# 自测提示词

## 当前改动自测。

```text
用 yanshi-self-test 检查 <当前改动>，业务依据是 <契约>。
先复用已有有效证据，再选能验证本次风险的最少检查。
需要新增测试时先确定 seam；本次是否选 TDD 以 <任务约定> 为准。
返回实际运行的检查、结果、覆盖目标、失败和未验证部分。
```

## 消融实验

第一句参数化为，第二句直接引用原文。

```text
本次叠加了三项优化：<优化一>、<优化二>、<优化三>。
给这三个优化设计消融实验，判断真正的收益来自哪里。
```

选择可比较的基线和移除或增加单项机制的对照；说明交互影响与其他条件差异。只设计未运行时，不填写收益数字。效果相近时再权衡保留收益和维护复杂度，不预设删除结论。

建议记录：改动版本；对应契约或目标；实际命令或操作；结果与证据；未覆盖部分；修复后需要重验的范围。「推断」
