# 实现者自测

> 来源见 README「来源」小节；本文件的自测范围与记录细则为（推断）。

1. 接收改动、契约、已有检查和运行能力。有效结果已覆盖当前改动时直接引用；只要求设计验证方案时不执行检查。
2. 选取与改动相关的类型检查、现有测试、业务断言或构建检查。需要新增代码层测试且本次选择 TDD 时：`Call the Skill tool with "tdd"`。没有 Skill 调用器时，读取同套件的 `../tdd/SKILL.md` 并按其执行。。缺失或受限时，在约定的 seam 上做 red → green；未选 TDD 时执行所需检查，不为流程制造测试代码。
3. 处理能由检查发现的问题；没有修改授权时返回缺陷。新增机制较多时检查必要性；多项优化需要归因且有可比条件时按需做消融实验。
4. 完成检查：所选检查有实际输入与结果，覆盖范围、失败和未执行项清楚；消融区分实验设计与实际观测。输出检查结果，按需保存 `self-test.md`；不能仅凭测试数量宣布业务完成。
5. 单独使用到本步结束；代码层自测不冒充真实业务 E2E。提示与结果字段见 [prompts.md](prompts.md)。
