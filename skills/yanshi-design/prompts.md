# 方案提示词

## 参数化第一性原理

保留原文原意，替换具体技术和问题为参数：。

```text
不要基于 <既定方案> 继续设计。从第一性原理分析 <问题为什么发生>，以及最小必要的解决方案。
目标与约束：<已确认结论>。
说明真正需要解决的原因、最小方案及仍待验证的核心假设。
```

## 对抗性审查

原文直接引用；把当前方案放在提示前即可。

```text
对这个方案做一次对抗性审查，优先寻找能推翻核心假设的反例。
```

## 做减法

原文直接引用。

```text
用奥卡姆剃刀重新审查这个设计，在满足需求的前提下，删除所有非必要机制。
```

## 组合版

原文直接引用，仅在任务确实需要这些认知动作时选用。

```text
从第一性原理重新分析，对当前方案做对抗性审查；核心机制必须通过消融实验验证；方案遵循奥卡姆剃刀，代码保持高内聚、低耦合。
```

组合句中的“必须”限定该次选择的验证要求，不扩展成全部任务的强制消融步骤；没有运行实验时只交付实验设计。「推断」
