# 总控提示词

以下均为「推断」，用于把原文的可裁剪工作流变成独立入口。

## 从需求开始

```text
用 yanshi 推进这个需求：<需求>。
先读取 <材料与代码位置>，复用已有结论。
按不确定性、业务风险和当前进度选择最短的有效路径，不以流程完整为目标。
你可以执行的范围是 <授权范围>；验收依据是 <契约来源>。
遇到会改变实现方向或验收结果的问题再问我；结束时给出证据与未验证项。
```

## 从中间继续

```text
用 yanshi 从这里继续：<当前状态与材料位置>。
这次只做 <允许的步骤或结果>，不重做已覆盖当前范围的有效工作。
先说明下一步和理由；失败时根据证据回到对应层处理。
预算与停止条件以 <已有约定> 为准，未约定的数值不要代填。
```
