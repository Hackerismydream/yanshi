# 选当前这一刻

先读 [project-context.md](project-context.md)。用一行 `[偃师·入口] <当前时刻> → <最短动作>` 说明打算怎么走，随后执行；不是先列一整套流程等人批准。

| 当前请求 | 只读这个入口 |
|---|---|
| 接到需求，影响方向或验收的问题还没想清楚 | [想清楚](../yanshi-think/SKILL.md) |
| 目标已经明确，要求写或修改实现 | [动手](../yanshi-build/SKILL.md) |
| 有报错、失败结果或“卡住了” | [排障](../yanshi-debug/SKILL.md) |
| 只要求审查、验收或提交前看一眼 | [验一下](../yanshi-check/SKILL.md) |
| 要换会话或交给另一位 Agent | [交接](../yanshi-handoff/SKILL.md) |
| 明确要求复盘、记住经验或沉淀项目规则 | [记下来](../yanshi-retro/SKILL.md) |

用户限定“只查 / 只审 / 不改代码”时保留这个边界。一个请求同时涉及几项时先做阻塞当前目标的那项，不重做已有结论；对齐完成不自动意味着获得编码授权。仅需简单修改时直接动手并自测，不额外生成 Spec、任务表或复盘文件。

内部路径相对于本文件；有调用器可以按真实名称调用，否则读取表中实际文件及其引用后执行。文件不存在时报告具体路径，不伪造成功或猜外部 Skill 位置。单入口可独立安装；需要本表全部分支时安装完整套件。

五个思维快捷键是用户随时插入的小命令，不是另五道关卡。未被主动选择时不逐个运行，也不绕过宿主的手动调用限制读取它们代跑。

任务结束只交代完成内容、实际证据与未验证部分。没有复盘请求就不启动记忆写入。预期结果来自业务契约，工具只负责提供证据。
