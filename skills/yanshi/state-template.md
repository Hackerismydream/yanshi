# 当前任务记录

可选模板，字段为「推断」。短任务可以直接在回复中记录，不必创建文件。

- 目标与范围：<本次要交付什么>
- 契约来源与版本：<已确认的需求或规则>
- 当前实现：<版本与未提交改动的识别信息>
- 授权与预算：<已有约定；未知则说明>
- 选用步骤及理由：<本次路径>
- 已完成与证据：<结果、位置及适用范围>
- 跳过或复用：<原因；复用证据位置>
- 未验证与阻塞：<缺口及影响>
- 待人决定：<问题和可选处理>
- 当前状态：<done / skipped / blocked / waiting-user>
- 下一步：<继续动作或本轮结束>

正式判定 E2E case 时使用该子 Skill 的证据模板；此记录只引用结论，不复制全部运行轨迹。
