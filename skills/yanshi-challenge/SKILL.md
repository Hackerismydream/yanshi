# 找反例

读 [project-context.md](project-context.md)；无目标项目时直接继续。以 `[偃师·找反例]` 开头，只做下面这个思考动作：

> 对这个方案做一次对抗性审查，优先寻找能推翻核心假设的反例。

给出反例与它推翻的假设；没有实际验证就不要把它说成已经发生的故障。 完成本命令后回到原任务，不自动串联其他快捷键。
