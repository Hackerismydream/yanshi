# 上下文交接

> 来源见 README「来源」小节；本文件的独立交接入口及字段为（推断）。

1. 接收当前目标、对话结论、改动和证据。当前上下文足够且没有交接需求时跳过。
2. 可调用且策略允许时：`Call the Skill tool with "handoff"`。没有 Skill 调用器时，读取同套件的 `../handoff/SKILL.md` 并按其执行。。缺失或受限时，将目标、契约、关键决策、变更位置、验证结果、未解决事项和下一步整理成简短交接材料。
3. 完成检查：接手者能区分事实、假设、已执行和未执行，知道从哪里继续；保留必要来源位置，不复制整段对话或敏感凭据。
4. 输出交接文本或按需保存 `handoff.md`。接手时重新确认版本、证据适用范围和授权；文件里写“已通过”本身不是通过证据。
5. 单独使用只生成交接，不自动启动新 Agent。提示见 [prompts.md](prompts.md)。
