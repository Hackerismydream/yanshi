# 可替换的执行与取证能力

能力方向来自 原文材料「三」与 E2E 材料；适配、降级和安全操作细则为。这是一份能力检查表，不是要求安装全部工具。

| 能力 | 本次需要知道什么 | 缺失时怎样处理 |
|---|---|---|
| 任务执行与调度 | 能接收自然语言目标、调用实际工具、读取结果、停止并保存记录 | 没有执行能力就只产出计划，不声称运行过 |
| 推理模型 | 能理解目标、跟踪状态并可靠用工具；吞吐与成本适合本次任务 | 不指定型号，以实际通过率、耗时和成本比较 |
| 环境准备 | 实际启动方式、待测版本、数据准备、清理或重置方法 | 必要条件不足时阻塞相应目标，不虚构可用命令 |
| 浏览器 | 测试登录态、页面交互、当前状态读取、截图或等效取证 | 用户要求 Web UI 时，API 证据不能代替 UI 通过 |
| API / CLI | 实际业务入口、身份、参数、响应和状态读取 | 可替代同一契约允许的入口；改变验证层次时明确报告 |
| 持久化状态读取 | 只读数据库或契约认可的权威查询入口，能关联目标对象 | 没有独立回读能力时，写操作成功提示不足以证明持久化 |
| 日志 / Trace | 按本次对象或请求定位链路，能解释失败 | 缺失时说明诊断限制，不用解释不足掩盖已有失败 |
| 证据保存 | 保存必要的操作、状态、时间和引用位置 | 无法留下可核对证据时，不对缺证据的目标判通过 |

## 准备的尺度

复用已配置的环境与工具。记录本次所用代码版本和未提交改动、环境、测试身份、权限和数据起点；需要时创建可隔离的测试数据。稳定脚本或 CLI 可以承接准备、查询和清理，不要求每次重建。

只使用已获准的测试身份、写入范围与目标环境。需要新增授权时暂停对应动作；密钥、会话凭据和共享材料中的敏感信息不写入交付记录。清理限定于本次创建或明确允许重置的数据。

## 持久化如何取证

先依据契约明确写入后应保持的状态，再实际操作，最后重新查询。浏览器内同一份前端状态或成功提示不能单独证明落库。能够满足契约的独立回读可以来自新请求、重新进入后的权威页面或只读数据库；具体选择取决于系统语义，不强制装数据库工具。

最终一致性场景只使用契约或现有环境约定的等待条件；没有明确时限就记录未知，不自行编造“等待足够久即通过”。

## 预期与观察分离

可以通过文档工具读取已确认的业务契约，但不能将被测系统刚返回的答案改写成预期。测试数据描述输入，契约定义这些输入应得到什么结果；当前代码、历史错误输出和测试通过数量都不自动成为正确性依据。

被测产品本身是 Agent 时，除路径是否跑通，还依据任务契约检查答案质量、来源或上下文约束。材料没有提供通用评分量表，本包不补造统一阈值。
