## 统一口径

一次完整任务为一个 trial。事先约定的内部重试属于同一 trial，时间和成本累加；重新开 trial 的补跑另报。每次尝试及原始失败仍保留。

P = passed，F = failed，B = blocked，U = not-run；原计划始终满足 `N = P + F + B + U`。探索不进入 N。

通过率为 `P / N`，同时报告原始分数及 F、B、U。N = 0 时无定义。环境故障、能力不足与未运行不能偷偷从分母删除；出现 B 或 U 时解释测量完整性和可比性。

单次耗时从环境就绪、目标交给 Agent 起，到终态报告及本轮约定的清理尝试结束止。包括内部重试、失败和超时；环境搭建耗时另列。

全体已尝试 trial 的平均耗时 = 总实际耗时 / `(P + F + B)`，同时给出分母。另列成功 trial 的平均耗时；快速失败不能被解释成更快完成任务。没有尝试或时间记录不全时，不计算完整均值。

模型成本包含所有已尝试 trial 的调用、内部重试和子 Agent 调用，统一币种，注明实际计费或估算依据。浏览器、harness 与环境成本另列，不把模型成本称为全链路成本。

成本缺失写未知，不按零计；已知部分只能报告为已知小计。没有完成全部计划，不能凭不完整总成本宣布某方案最便宜。
