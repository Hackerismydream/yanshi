## 默认口径

一次完整任务运行为一个 trial。预先允许的工具重试仍属于同一 trial，时间与模型成本累计；修复代码或重新开一轮 trial 后的结果另报，不能替换原失败。

每个方案的原定 N 个 trial 分为：P 个通过、F 个失败、B 个阻塞、U 个未运行，满足 `N = P + F + B + U`。探索运行另外报告，不混入正式通过率。

通过率为 `P / N`，同时给出原始分数与 F、B、U。U 或环境性阻塞存在时说明测量是否完整；能力本身无法完成目标的情况不能悄悄剔除。

单次耗时从环境就绪、目标交给 Agent 起，到终态报告和本轮约定的清理尝试结束止；包含实际失败、超时与内部重试。环境搭建耗时单列。平均耗时取已尝试 trial，即 `总实际耗时 / (P + F + B)`，并报告这个分母；没有尝试则为未知。

模型成本为所有已尝试 trial 的调用成本之和，包含内部重试和子 Agent 调用；同时可以给出每个已尝试 trial 的平均成本。使用相同币种，说明实际计费或估算及其依据。浏览器、harness、环境成本另列，不能把“模型成本”叫作全链路总成本。

成本缺失写未知，不按零计；时间记录不全则不计算完整平均值。N 为零时通过率无定义，不给出百分比。未完成全部运行时，不用不完整总成本宣布某组合最便宜。
