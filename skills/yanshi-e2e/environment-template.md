# 项目环境卡

从项目文档、已有脚本、工具配置或负责人回答填写。不存在的命令不填；凭据只记录获取方式，不记录秘密值。

| 项目 | 实际值与依据 |
|---|---|
| 被测版本、未提交改动、部署环境 | <版本及确认位置> |
| 业务入口与验收层次 | <真实地址或已有命令；UI / API / CLI> |
| 启动与就绪检查 | <项目已有方法；已运行结果或未运行> |
| 身份与权限 | <测试身份、授权范围、会话准备方法> |
| 数据准备与隔离 | <起点、目标对象、已有准备方法> |
| 权威状态读取 | <真实查询工具或入口，如何避开同一前端缓存> |
| 日志与 Trace | <实际查询方式及请求 / 对象关联字段> |
| 清理或重置 | <项目已有方法、限定对象、失败时由谁处理> |
| 执行限制 | <已有预算、超时、写入授权、禁止触碰的环境> |

## 能力不足时怎样处理

需要 UI 但没有浏览器：UI 目标阻塞，API 调查单列。
需要持久化证据但无法独立回读：该断言未验证，不能把 case 判通过。
没有日志：可以凭充分的行为证据判定结果，但不编造失败原因。
缺少安全的写入身份或范围：不执行写入，返回对应缺口。
目标要求等待终态但没有等待约定：先确认可据以判断的终态与边界。
